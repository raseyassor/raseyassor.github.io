6. Méthodologie
Sources de données, modèles, normes
Sources de données
  • Météo : ERA5 avec réanalyse PVGIS v5.3 — horaire
  • Horizon : Calculé par MNE (PVGIS)
Modèles
  • Transposition : Hay-Davies (direct + isotrope + circumsolaire + brillance d’horizon)
  • Température cellule : Sandia (NOCT + vent)
  • IAM : Martin & Ruiz (réflexion selon l’angle)
  • Correction spectrale : masse d’air + paramétrisation PW (PVGIS)
  • P50/P90 : moyenne ± t₉₀ × s × √(1 + 1/N) avec loi de Student
  • Financier : DCF — VAN, TRI (recherche dichotomique), amortissement, LCOE
  • Dégradation : réduction linéaire annuelle
Normes
  • Ratio de performance selon IEC 61724-1:2017
  • Indicateurs financiers selon les lignes directrices IEA PVPS Task 13
